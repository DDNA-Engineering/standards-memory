# StandardsForge logo

`standardsforge-mark.png` is the project logo used in the root README. The navy-and-orange SF mark has an intentional solid white background. Keep the original aspect ratio and clearspace when reusing it. The wordmark remains live text so it stays readable and accessible.

Generated with the built-in image generation tool using the prompt below. This is a generated raster asset, not an editable vector master.

## Generation prompt

```text
Use case: logo-brand.
Asset type: final logo mark for StandardsForge, an open-source engineering standards compiler and source-linked evidence engine used to build robust, reliable products.
Primary request: create one distinctive, polished geometric emblem. The emblem should suggest precision-machined interlocking components and a strong foundation, with an elegant abstract SF monogram integrated through negative space. Bold, simple silhouette with carefully aligned straight edges and restrained chamfered corners. Professional industrial design, calm and durable, suitable for a technical GitHub project. A single coherent mark, not a collection of options.
Style: flat vector-like graphic with razor-sharp edges, uniform solid fills, sophisticated optical balance; readable at small icon sizes.
Color palette: charcoal navy and a restrained forge-orange accent. Both colors should remain recognizable against light and dark interfaces.
Composition: square canvas; single centered compact logo occupying about 80 percent of the canvas, generous even clearspace. Actual transparent background, preserve alpha.
Text: no wordmark, no slogan, no text outside the abstract monogram.
Avoid: emojis, mascots, shields, certification seals, checkmarks, books, document sheets, literal hammers, flames, sparks, gradients, shadows, 3D, mockups, borders, watermarks, busy thin detail.
```
