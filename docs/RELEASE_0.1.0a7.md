# StandardsForge v0.1.0a7 release evidence

Release candidate prepared October 8, 2026. Publication and artifact identities will be recorded after native acceptance and public readback.

## Changes

One portable setup implementation now handles offline core installation, the exact Windows x64 CPython 3.12 MCP wheelhouse, and explicitly requested online MCP dependencies on supported platforms. Windows users can double-click `setup.cmd`; Linux/macOS users run `sh setup.sh --mcp-online`. Setup generates absolute host configuration after a real stdio smoke. Revalidation failures cannot retain the prior readiness receipt. The MCP launcher validates bundle-bound readiness and accepts no caller overrides.

The runtime includes eleven read-only operations, including structural browsing, measured evidence selection, reviewed-reference navigation and original source PDF delivery. All query paths retain local authorization and source verification.

## Content baseline

The prepared release retains the a6 acquisition and representation baseline: 438 page packs from 912 PDFs, one automated outline-v3 and two bounded MIL-STD-1661 recovery packs, totaling 441 packages. All three real-document suites (52 cases) must be rerun against the exact new wheel sources. Upgrading the runtime does not imply corpus-wide semantic review or add outline-v4 to the released content.

## Acceptance

Pending release qualification. The source suite, contract gate, synthetic benchmark, reproducible wheel and starter checks, native prepared installation, real MCP queries, public archive checksums and exact PyPI identity are separate evidence stages.

This remains an alpha release. Bounded observed acceptance does not establish corpus-wide visual or semantic completeness, applicability, compliance or human approval.
